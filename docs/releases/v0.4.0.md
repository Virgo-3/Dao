# Dao v0.4.0

Released from commit [`ca12d51ee06e5e9f47738f3cb5aaf4129d78b085`](https://github.com/Virgo-3/Dao/commit/ca12d51ee06e5e9f47738f3cb5aaf4129d78b085). This tag fixes the source used for both the Windows executable and source archives. Later changes on `main`, including the refreshed Memory interface, are outside this release.

## Changes since v0.3.0

- Conversation and semantic structure stay together through source passages, typed notes, and directed dependencies.
- Common phrases capture decisions with their reasons, tentative possibilities, and working assumptions. Recall retrieves saved reasoning; conversational branching explores alternatives with separate context.
- Corrections preserve earlier context and flag affected decisions for reconsideration. Competing choices or a retraction in the same message require clarification before settled memory is saved.
- Advanced structure changes remain reviewable proposals, with source citations and explicit acceptance or rejection.
- Dao is the sole application; the separate Dao Narrative interface has been removed. Both the terminal and browser use the same persistent local state.

## Engine fixes

- Small positive utilities remain eligible, and action tie-breaking reports the selected action's own utility while respecting the confidence margin.
- Identical information signals no longer create a spurious reason to wait through floating-point roundoff.
- Variance calculations avoid inflated risk from rounding a large common payoff offset.
- Evidence thresholds compare exact decimal means, accepting equality while rejecting values strictly below the threshold.
- Same-message decision retractions are checked across the entire message, including when a model cites only an earlier clause.

## Windows download

Download [Dao-windows-x64-0.4.0.zip](https://github.com/Virgo-3/Dao/releases/download/v0.4.0/Dao-windows-x64-0.4.0.zip), extract it, and run `Dao.exe` for the terminal or `Dao.exe --web --open-browser` for the browser workspace. Python is bundled. The default offline demo needs no account or API key; live AI uses process environment settings.

The executable is unsigned. The ZIP includes `SHA256SUMS`; compare its hash with `Get-FileHash .\Dao.exe -Algorithm SHA256`. A matching checksum confirms the downloaded executable matches the published checksum. See the [Windows guide](https://github.com/Virgo-3/Dao/blob/ca12d51ee06e5e9f47738f3cb5aaf4129d78b085/docs/windows.md) for launch options, state location, and configuration.
